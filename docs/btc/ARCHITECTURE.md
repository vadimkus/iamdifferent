## API Endpoints

### /api/btc/binance (10s refresh)
**Source:** Binance public REST API (no auth)
- `GET /api/v3/ticker/24hr?symbol=BTCUSDT` — price, volume, 24h stats
- `GET /api/v3/depth?symbol=BTCUSDT&limit=10` — order book
- `GET /api/v3/klines?symbol=BTCUSDT&interval=1h&limit=24` — hourly volume

**Returns:** Real-time price, 24h high/low/volume, spread, top-10 order book, bid/ask walls, market pressure (bid/ask ratio), hourly volume ratio.

### /api/btc/alpha-strategy (60s refresh)
**Sources:** Binance (price, volume) + Yahoo Finance (indicators) + market-events.ts (calendar)

**Logic:**
1. Fetches Binance real-time price + Yahoo 6mo daily BTC + 1mo daily DXY in parallel
2. Computes RSI(14), EMA(20), SMA(200), Bollinger Bands, MACD from Yahoo daily data
3. Uses Binance price for all price-level comparisons
4. Uses Binance hourly volume ratio (falls back to Yahoo daily if Binance fails)
5. Evaluates 3 strategy condition sets
6. Computes buy window based on current Dubai time

**Returns:** Overall signal, 3 strategy setups with conditions, timing, backtest stats.

### /api/btc/weekly-strategy (60s refresh)
**Sources:** Binance (price, volume) + Yahoo Finance (2y BTC, 1mo DXY/VIX/SPX) + market-events.ts

**Logic:**
1. Fetches Binance real-time BTC price + Yahoo 2y daily BTC, 1mo DXY/VIX/SPX in parallel
2. Computes RSI(14), SMA(200), weekly return from Yahoo daily data
3. Evaluates 7 strict Tier 1 conditions and 5 relaxed Tier 2 conditions
4. Assigns the current Friday to Tier 1 (6+/7), Tier 2 (4+/5 and not T1), or Tier 3 (remainder)
5. Returns active tier with TP/SL/hold, exact dollar amounts for $270K position, and buy window status

**Returns:** Active tier signal, conditions, trade params, annual projection, all-tier backtest stats.

### /api/btc/live (60s refresh)
**Source:** Yahoo Finance (`yfinance` via `yfChart`)
- BTC-USD 2y daily — RSI, MACD, Bollinger, EMA, SMA 200
- ^GSPC (SPX) 6mo daily — RSI, EMA, SMA, 52w range
- ^VIX 6mo daily — VIX level, SMA 20, zone classification

**Returns:** Full technical indicator snapshot for BTC, SPX, VIX.

### /api/btc/friday-timing (static, daily revalidation)
**Source:** Pre-computed JSON from `btc/friday_timing_results.json`

Generated by `btc/friday_timing.py` which analyzed:
- 10 years of daily BTC data (522 Fridays)
- 2 years of hourly BTC data (104 Fridays, 12 entry hours)
- Month × Hour cross-tabulation
- Volume effect analysis
- TP/SL simulation for each entry hour

**Returns:** Ranked entry hours, monthly stats, yearly stats, cross table.

### /api/btc/chart (on demand)
**Source:** Yahoo Finance hourly/daily BTC data

Supports intervals: 1h, 2h, 4h, 1d. The 2h and 4h intervals are aggregated from 1h candles. Includes EMA 20/50, SMA 200, and RSI overlays.

### /api/btc/events (static)
**Source:** `src/lib/market-events.ts` hardcoded calendars

Provides lunar events (full/new moons, eclipses), FOMC meeting dates, and Mag7 earnings dates for chart overlays.

### /api/btc/macro (once on load)
**Source:** FRED API (API key: `2a948cee2bd38aff557c01946bfc5110`)
- M2 Money Supply (10-year history + latest + MoM/YoY)
- Fed Balance Sheet
- Fed Funds Rate
- 10Y-2Y Treasury Yield Curve

### /api/btc/dxy (once on load)
**Source:** Yahoo Finance `DX-Y.NYB` 1mo daily

### /api/btc/correlations (once on load)
**Source:** Yahoo Finance BTC, SPX, Gold 2y daily
- 30-day rolling correlation matrix
- Current correlation snapshot

## Shared Libraries

### src/lib/btc-data.ts
Core data fetching and indicator computation:
- `yfChart(ticker, range, interval)` — Yahoo Finance OHLCV
- `calcRSI(closes, period)` — Relative Strength Index
- `ema(data, period)` — Exponential Moving Average
- `sma(data, period)` — Simple Moving Average
- `calcMACD(closes)` — MACD + Signal + Histogram
- `calcBollinger(closes, period, mult)` — Bollinger Bands
- `fredSeries(seriesId)` — FRED economic data

### src/lib/market-events.ts
Hardcoded event calendars (2024-2026):
- `FULL_MOONS`, `NEW_MOONS` — lunar phase dates
- `LUNAR_ECLIPSES`, `SOLAR_ECLIPSES` — eclipse dates
- `FOMC_DATES` — Federal Reserve meeting dates
- `MAG7_EARNINGS` — Apple, Microsoft, Google, Amazon, Meta, Nvidia, Tesla earnings
- Helper functions: `daysToFullMoon()`, `nearEclipse()`, `isFOMCWindow()`, `nearbyEarnings()`, `moonPhaseToday()`

## Deployment

- **Platform:** Vercel (automatic deploy from `main` branch)
- **Runtime:** Node.js serverless functions for API routes
- **Static data:** `btc/friday_timing_results.json` read from filesystem at runtime; `weekly_strategy_results.json` is reference only (configs hardcoded in API route)
- **Environment:** No env vars needed — all APIs are public or key is hardcoded

## Research Pipeline (Offline)

```
btc/research.py
  ├── Fetches 10yr BTC, SPX, Gold, DXY, VIX from yfinance
  ├── Computes 30+ indicators per asset
  ├── Tests 508 strategy combinations (1-4 condition combos)
  ├── Evaluates TP/SL/Hold for each using vectorized NumPy
  └── Outputs btc/research_results.json

btc/weekly_strategy.py
  ├── Fetches 10yr BTC, DXY, VIX, SPX, Gold from yfinance
  ├── Builds Friday-only DataFrame with 12 conditions
  ├── Defines 3 tiers (strict, relaxed, base) with different thresholds
  ├── Exhaustive TP/SL scan per tier (21 combos each)
  ├── Combined simulation across all 522 Fridays
  └── Outputs btc/weekly_strategy_results.json

btc/friday_timing.py
  ├── Fetches 10yr daily + 2yr hourly BTC
  ├── Analyzes every Friday entry hour (12-23 UTC)
  ├── Simulates TP +0.5% / SL -1% for each hour
  ├── Builds month × hour cross table
  └── Outputs btc/friday_timing_results.json
```

To re-run research:
```bash
cd btc
pip3 install -r requirements.txt
python3 research.py          # ~2 minutes, outputs research_results.json
python3 weekly_strategy.py    # ~12 seconds, outputs weekly_strategy_results.json
python3 friday_timing.py     # ~15 seconds, outputs friday_timing_results.json
```
